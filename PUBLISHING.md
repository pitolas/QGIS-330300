# Publicação no repositório oficial do QGIS

Esta versão foi preparada para publicação pública como v1.0.0.

## Antes do envio ao plugins.qgis.org

1. Crie o repositório público: `https://github.com/pitolas/QGIS-330300`.
2. Envie para ele os arquivos deste pacote-fonte.
3. Confirme que estes endereços estão acessíveis:
   - https://github.com/pitolas/QGIS-330300
   - https://github.com/pitolas/QGIS-330300/issues
4. Teste o arquivo `QGIS_330300_v1.0.0.zip` no QGIS 3.44.14.
5. Faça login no portal de plugins do QGIS com seu OSGeo ID e envie o ZIP instalável.

Se o nome do repositório GitHub for alterado, atualize `repository`, `homepage`, `tracker` em `metadata.txt` e `repository-code` em `CITATION.cff` antes da publicação.
