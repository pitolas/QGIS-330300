about=Independent QGIS plugin for configurable spatial analysis of the 3-30-300 urban green infrastructure rule. It evaluates a minimum number of mapped trees around parcels, minimum neighborhood tree canopy coverage, and maximum distance from parcels to parks or protected green spaces. The original criterion of three visible trees is operationalized in this GIS implementation as a configurable number of mapped trees within a user-defined distance from each parcel. The plugin provides diagnostic output layers, summary statistics and optional automatic symbology. No external software dependency is required.
